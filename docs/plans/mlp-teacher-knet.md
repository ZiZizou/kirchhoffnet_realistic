## Idea
Create dagger-mlp-distillation-kirchhoffnet.py, a KirchhoffNet DAgger distillation script that mirrors dagger-nuance-distillation-kirchhoffnet.py structure (LocalKirchhoffStudentWrapper, RegimeAwareLoss/RampedRegimeLoss, StudentEvaluator, DistillationDataset, checkpoint/resume, COMMON_EVAL_SPECS, failure-capped iteration) but replaces the generative FlowTeacherLabeler/ConditionalSplineFlow teacher with a frozen PlainMLP teacher trained by generative-distillation-plain-mlp.py. Teacher is loaded from a .pt state_dict (default outputs/dagger_output_plain_mlp_w48_preprocessing_knet/dagger_student_plain.pt, matching the user's actual run: --param-budget 5559 --plain-trunk-layers 3 --dagger-iterations 4 --epochs-per-iter 100 --common-eval-size 1000 --input-preprocessing knet --seed 100 → W=48 L=3 SiLU no-LN knet preprocessing, ~5479 params). Extend ctle_dagger_common.py with MlpTeacherLabeler + load_plain_mlp_teacher + create_mlp_distillation_dataset (batched single-pass MLP forward, no candidate sampling) and keep ZIG/HybridHurdleModel for StudentEvaluator and RegimeAwareLoss evaluation. Student remains LocalKirchhoffStudentWrapper with same KN_* topology defaults. Invalidate initial-dataset cache hash to include mlp checkpoint identity instead of flow candidate budgets.
