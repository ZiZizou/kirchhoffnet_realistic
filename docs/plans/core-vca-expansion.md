## Idea
Two-part change to the low-rank VCA feature in DifferentialStage. (1) FIX the boundary/readout VCA regression: the current init produces gate=σ(z)≈0.5 at init (a −6dB gain cut on the entire I/O path), so VCA consistently underperforms baseline (friedman2: 6.65e-5 → 1.11e-4; housing: 0.1159 → 0.1329). Fix = zero-init vca_W entirely (all columns) so z=(u@W)@v_e.T=0 for every edge → gate=2·σ(z)=1.0 exactly, making epoch-0 bit-identical to VCA-off. Embeddings stay random so vca_W receives gradient at step 0 (via u⊗v_e path). (2) ADD core-edge VCA: a new vca_v_core embedding (n_core_edges × rank) tapping the shared vca_W bus, gating core tanh currents. Because u is constant per sample, the gate folds into the existing freeze_read precompute with zero extra Heun-loop cost, and even in the freeze_read-OFF path it is computed once per sample at stage entry and cached (compile-safe non-persistent buffer). The core gate makes each node's frozen bias b_j(u) literally a one-hidden-layer sigmoid network from inputs — a real function-class addition on static tasks like friedman2. Includes: --vca-gate-shunt (gates the unfrozen resistive shunt, default off), --vca-separate-core-bus (own W_core, default shared), relaxation of the boundary/readout requirement for core-only VCA, all VCA params moved to the structural 4x LR group, sanity checks (identity at epoch 0, gradient flow, cache freshness), logging of gate distributions, and an A–E experiment grid runner (3 seeds each) on friedman2.

- Implement hoisted core gate cache in differential_stage.py. Compute + store ONCE per sample at stage entry in ALL forward entry points: _forward_heun (before loop at 925), _forward_heun_sequence (per-sample in loop at 1024), forward_equilibrium (before phi at 1159). Buffer (not plain attribute) so torch.compile'd rhs/train_script (line 3467) treats it as a graph input, not a per-sample recompile trigger. - Freeze_read ON integration (production path): at each of the 3 freeze_read precompute sites, multiply the frozen tanh current by the cached core gate before scatter-add: i_edge = i_edge * edge_mask * gate_core_cached (broadcast [B, E_core]). This makes i_edge_const input-dependent b_j(u) with zero change to the Heun loop.

Add shunt gating: when self.vca_gate_shunt and vca core enabled, i_res = i_res * edge_mask.unsqueeze(0) * gate_core_cached (after line 745). Guard with a check that the cache is populated for the current batch (set by caller).
