# Golden numerical baseline (pre-surgery)

Files in `data/*.pt` were generated by `make_golden.py` at git tag `pre-surgery`
(branch `hw-refactor`) with torch 2.15 CPU. Do NOT regenerate them during surgery;
regenerating would erase the very thing they protect. Regenerate only on purpose,
e.g. after an intentional retrain-related change, and say so in the commit.

    venv/bin/python -m pytest tests/test_golden.py -q        # ~20 s
    venv/bin/python tests/golden/make_golden.py [--only paper ...]   # rewrite goldens

## What each golden file holds
`spec` (build kwargs), `state_dict` (full, incl. int `src/dst/boundary_*/readout_sense_src`
buffers), `sorted_keys`, `n_params`, `inputs` (64 rows), `target`, `y` (forward),
`stage_states` (per-stage final state, `core.last_stage_outputs`), `loss` (MSE to a fixed random
target), `grads` (every named parameter after one backward), `no_grad_names`,
and for `friedman2` / `toy_mimo` a 30-step Adam `traj` (losses, final state_dict, data).

## Cases
fixed_mlp_knet (trained bundle, float64 re-run), paper (5,649 params, noise-perturbed init),
paper_rawinit (raw seeded init, unperturbed), friedman2, toy_mimo (4->3), and paper variants:
freeze_read_off, vca_off, gln_off, gln_boundary_only, clip_off, readout_temporal (ota_mesh),
readout_shared (x1), vca_gate_shunt, vca_bias, vca_shared_core_bus, vca_core_off, interstage_none.

## Extending the removal steps
In `tests/test_golden.py`: add fnmatch patterns to `IGNORED_KEYS` (dropped from both the golden and
the rebuilt model's state_dict, grads and parameter comparisons) and build-kwarg changes to
`SPEC_OVERRIDES`. `make_golden.py` holds the only adapters that touch model call signatures
(`_net_forward`, `_stage_states`, `_build_net`, `_core`); update those if signatures change.

## Known limits
* Several KCL scatter accumulators in `differential_stage.py` are hard-coded `torch.float32`
  (`acc = zeros_like(x, dtype=torch.float32)`), so the forward is float64 at the interface but
  carries ~1e-7 relative rounding. Tolerances (rtol 1e-6, atol 1e-7; trajectory 1e-5) account for it.
* The raw random init gives outputs with std ~1e-5, so golden `paper` etc. add seeded N(0, 0.5^2)
  noise to every parameter (saved in the state_dict). `paper_rawinit` keeps the unperturbed init.
* `u_logits` (node gates) never receive gradient; the test asserts that set stays identical.
